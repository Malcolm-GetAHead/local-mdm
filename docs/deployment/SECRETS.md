# Secrets Management

**Version**: 1.0  
**Last Updated**: 2026-02-06

## Overview

Local MDM uses different secrets management strategies for development and production environments.

---

## Development (File-Based)

### Current Implementation

Secrets are stored in the `secrets/` directory as individual files.

```
secrets/
├── .gitignore              # Ignore all files in this directory
├── README.md               # Setup instructions
├── db_password             # PostgreSQL password
├── jwt_secret              # JWT signing key (256-bit)
├── keycloak_client_secret  # Keycloak OIDC client secret
├── apns_cert.pem           # APNs certificate (macOS push)
├── apns_key.pem            # APNs private key
└── ca_key.pem              # Root CA private key
```

### Setup Instructions

1. Create the secrets directory:
```bash
mkdir -p secrets
```

2. Generate secrets:
```bash
# Database password
openssl rand -base64 32 > secrets/db_password

# JWT secret (256-bit)
openssl rand -base64 32 > secrets/jwt_secret

# Keycloak client secret (from Keycloak admin console)
echo "your-keycloak-client-secret" > secrets/keycloak_client_secret

# CA private key (generated by S1-03 task)
# Will be created automatically on first run

# APNs certificate (upload via API after enrollment)
# Will be stored here after upload
```

3. Set permissions:
```bash
chmod 600 secrets/*
```

### Configuration

```yaml
# configs/config.yaml
secrets:
  source: "file"
  file_path: "./secrets"
```

### Loading Secrets

```go
// internal/config/secrets.go
func LoadSecretsFromFile(path string) (*Secrets, error) {
    secrets := &Secrets{}
    
    secrets.DBPassword = readFile(filepath.Join(path, "db_password"))
    secrets.JWTSecret = readFile(filepath.Join(path, "jwt_secret"))
    secrets.KeycloakClientSecret = readFile(filepath.Join(path, "keycloak_client_secret"))
    
    // Optional secrets (may not exist yet)
    secrets.APNsCert = readFileIfExists(filepath.Join(path, "apns_cert.pem"))
    secrets.APNsKey = readFileIfExists(filepath.Join(path, "apns_key.pem"))
    secrets.CAKey = readFileIfExists(filepath.Join(path, "ca_key.pem"))
    
    return secrets, nil
}
```

## Production (AWS Secrets Manager)

### Future Implementation

In production, secrets will be stored in AWS Secrets Manager or SSM Parameter Store.

### AWS Secrets Manager

**Secret Names**:
```
/localmdm/{environment}/db_password
/localmdm/{environment}/jwt_secret
/localmdm/{environment}/keycloak_client_secret
/localmdm/{environment}/apns_cert
/localmdm/{environment}/apns_key
/localmdm/{environment}/ca_key
```

**Configuration**:
```yaml
# configs/config.yaml
secrets:
  source: "aws_secrets_manager"
  aws_region: "us-east-1"
  secret_prefix: "/localmdm/production"
```

**IAM Permissions Required**:
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "secretsmanager:GetSecretValue",
        "secretsmanager:DescribeSecret"
      ],
      "Resource": "arn:aws:secretsmanager:us-east-1:123456789012:secret:/localmdm/production/*"
    }
  ]
}
```

**Loading Secrets**:
```go
// internal/config/secrets_aws.go
func LoadSecretsFromAWS(region, prefix string) (*Secrets, error) {
    sess := session.Must(session.NewSession(&aws.Config{
        Region: aws.String(region),
    }))
    
    svc := secretsmanager.New(sess)
    secrets := &Secrets{}
    
    secrets.DBPassword = getSecret(svc, prefix+"/db_password")
    secrets.JWTSecret = getSecret(svc, prefix+"/jwt_secret")
    secrets.KeycloakClientSecret = getSecret(svc, prefix+"/keycloak_client_secret")
    
    // Optional secrets
    secrets.APNsCert = getSecretIfExists(svc, prefix+"/apns_cert")
    secrets.APNsKey = getSecretIfExists(svc, prefix+"/apns_key")
    secrets.CAKey = getSecretIfExists(svc, prefix+"/ca_key")
    
    return secrets, nil
}
```

### AWS SSM Parameter Store (Alternative)

**Parameter Names**:
```
/localmdm/{environment}/db_password
```

**Configuration**:

**IAM Permissions Required**:

## Migration Path

### From File-Based to AWS Secrets Manager

1. **Export secrets from files**:
```bash
#!/bin/bash
# scripts/export-secrets-to-aws.sh

ENVIRONMENT="production"
REGION="us-east-1"
PREFIX="/localmdm/${ENVIRONMENT}"

# Create secrets in AWS Secrets Manager
aws secretsmanager create-secret \
  --name "${PREFIX}/db_password" \
  --secret-string "$(cat secrets/db_password)" \
  --region ${REGION}

aws secretsmanager create-secret \
  --name "${PREFIX}/jwt_secret" \
  --secret-string "$(cat secrets/jwt_secret)" \
  --region ${REGION}

aws secretsmanager create-secret \
  --name "${PREFIX}/keycloak_client_secret" \
  --secret-string "$(cat secrets/keycloak_client_secret)" \
  --region ${REGION}

# Optional: APNs certificates (if they exist)
if [ -f secrets/apns_cert.pem ]; then
  aws secretsmanager create-secret \
    --name "${PREFIX}/apns_cert" \
    --secret-string "$(cat secrets/apns_cert.pem)" \
    --region ${REGION}
fi

if [ -f secrets/apns_key.pem ]; then
  aws secretsmanager create-secret \
    --name "${PREFIX}/apns_key" \
    --secret-string "$(cat secrets/apns_key.pem)" \
    --region ${REGION}
fi

# CA private key
if [ -f secrets/ca_key.pem ]; then
  aws secretsmanager create-secret \
    --name "${PREFIX}/ca_key" \
    --secret-string "$(cat secrets/ca_key.pem)" \
    --region ${REGION}
fi
```

2. **Update configuration**:
```yaml
# configs/config.production.yaml
secrets:
  source: "aws_secrets_manager"
  aws_region: "us-east-1"
  secret_prefix: "/localmdm/production"
```

3. **Deploy with new configuration**:
```bash
# Ensure IAM role has required permissions
# Deploy application
# Verify secrets are loaded correctly
```

4. **Remove file-based secrets**:
```bash
# After verifying AWS secrets work
rm -rf secrets/
```

## Secret Rotation

### Manual Rotation

1. **Generate new secret**:
```bash
openssl rand -base64 32 > secrets/jwt_secret.new
```

2. **Update in AWS Secrets Manager**:
```bash
aws secretsmanager update-secret \
  --secret-id /localmdm/production/jwt_secret \
  --secret-string "$(cat secrets/jwt_secret.new)"
```

3. **Restart application**:
```bash
# Application will load new secret on startup
kubectl rollout restart deployment/localmdm
```

### Automated Rotation (Future)

- AWS Secrets Manager supports automatic rotation
- Lambda function to generate new secrets
- Zero-downtime rotation with dual-secret support

## Security Best Practices

### File-Based (Development)

1. **Never commit secrets to git**:
```gitignore
# .gitignore
secrets/
!secrets/.gitignore
!secrets/README.md
```

2. **Restrict file permissions**:
```bash
chmod 700 secrets/
chmod 600 secrets/*
```

3. **Use separate secrets per environment**:
```
secrets/dev/
secrets/staging/
secrets/production/
```

### AWS Secrets Manager (Production)

1. **Use IAM roles, not access keys**:
   - ECS task role
   - EKS service account
   - EC2 instance profile

2. **Enable encryption at rest**:
   - Use AWS KMS customer-managed keys
   - Separate KMS keys per environment

3. **Enable audit logging**:
   - CloudTrail logs all secret access
   - Monitor for unauthorized access

4. **Implement least privilege**:
   - Only grant access to required secrets
   - Use resource-based policies

5. **Enable secret versioning**:
   - Keep previous versions for rollback
   - Automatic version management

## Troubleshooting

### File-Based Secrets

**Problem**: Secret file not found  
**Solution**: Ensure file exists and has correct permissions
```bash
ls -la secrets/
```

**Problem**: Permission denied  
**Solution**: Fix file permissions
```bash
chmod 600 secrets/*
```

### AWS Secrets Manager

**Problem**: Access denied  
**Solution**: Check IAM permissions
```bash
aws secretsmanager get-secret-value \
  --secret-id /localmdm/production/db_password
```

**Problem**: Secret not found  
**Solution**: Verify secret name and region
```bash
aws secretsmanager list-secrets --region us-east-1
```

**Problem**: Slow startup  
**Solution**: Secrets are cached after first load. Consider using AWS Secrets Manager caching library.

## Environment Variables Override

For both file-based and AWS secrets, environment variables can override:

```bash
# Override database password
export LOCALMDM_DB_PASSWORD="override-password"

# Override JWT secret
export LOCALMDM_JWT_SECRET="override-jwt-secret"
```

**Priority** (highest to lowest):
1. Environment variables
2. AWS Secrets Manager / SSM
3. File-based secrets
4. Default values (if any)

## Backup and Recovery

### File-Based Secrets

**Backup**:
```bash
# Encrypted backup
tar czf secrets-backup.tar.gz secrets/
gpg --encrypt --recipient admin@example.com secrets-backup.tar.gz
```

**Restore**:
```bash
gpg --decrypt secrets-backup.tar.gz.gpg | tar xzf -
```

### AWS Secrets Manager

**Backup**:
- Secrets Manager automatically maintains version history
- Export to encrypted S3 bucket for disaster recovery

**Restore**:
- Restore from previous version
- Import from S3 backup if needed
