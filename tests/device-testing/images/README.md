# VM Images Directory

Place your VM installation images here:

## Files to Place Here

- `windows-11-arm.iso` - Windows 11 ARM Insider Preview
- `macos-26.ipsw` - macOS 26 IPSW (or let UTM auto-download)
- `android-x86.iso` - Android x86 ISO (optional, not recommended)

## Download Links

**Windows 11 ARM**:
- https://www.microsoft.com/en-us/software-download/windowsinsiderpreviewARM64

**macOS IPSW**:
- UTM can auto-download, or manually from:
- https://ipsw.me/VirtualMac2,1

**Android x86** (not recommended for MDM testing):
- https://www.android-x86.org/download
- https://sourceforge.net/projects/blissos-x86/

## Note

These files are gitignored and will not be committed to the repository.
Large files (10-15 GB each) - keep them here for VM creation with UTM.
